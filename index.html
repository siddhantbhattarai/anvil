🔨 ANVIL

An evidence-driven web application security scanner in Rust. It doesn't flag — it proves: 11 active vulnerability classes and 5 passive audits across 8 of the OWASP Top 10, with a low false-positive rate.

Install via apt View on GitHub →

Install — Debian / Ubuntu

# add the signing key and repository
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://siddhantbhattarai.github.io/anvil/pubkey.gpg \
  | sudo tee /etc/apt/keyrings/anvil.asc > /dev/null

echo "deb [signed-by=/etc/apt/keyrings/anvil.asc] https://siddhantbhattarai.github.io/anvil stable main" \
  | sudo tee /etc/apt/sources.list.d/anvil.list

sudo apt update
sudo apt install anvil

Updates then arrive through apt upgrade like any other package. The repository metadata is GPG-signed; apt verifies every download against the key above. The optional headless XSS check uses a system Chrome/Chromium — sudo apt install chromium to enable it.

What it proves

Injection

SQLi (UNION, boolean/time blind, error, OOB, stacked, second-order), NoSQLi, command injection, SSTI, CRLF — each confirmed by a working oracle.

XSS, actually executed

Reflected, stored and DOM XSS verified by real execution in a headless browser — a canary sets window.__ANVIL_XSS__ before it's called a finding.

SSRF

Internal-network probing (RFC1918), cloud metadata endpoints (AWS/GCP/Azure), alternate schemes, and blind SSRF via out-of-band callbacks.

Access & redirects

Path traversal / LFI, open redirect, CORS misconfiguration, XXE — the black-box A01 and integrity classes.

Passive audits

Security headers & cookie flags, JWT weaknesses, exposed secrets, outdated JS components with known CVEs, missing Subresource Integrity.

Automation & agents

--owasp one-shot sweep, deterministic --fail-on exit codes for CI, JSON/CSV output, and a native MCP server for AI agents.

Use

# full OWASP sweep with crawling, JSON report
anvil -t http://target.com --owasp --crawl -o report.json --format json

# CI / agent gate: exit 2 if anything High or worse is found
anvil -t http://target.com --owasp --fail-on high

# targeted single-class checks
anvil -t "http://host/page?id=1" -p id  --sqli --dbs
anvil -t "http://host/search?q=t" -p q  --xss --xss-all
anvil -t "http://host/fetch?url=x" -p url --ssrf

# run as an MCP server for AI agents (stdio JSON-RPC)
anvil --mcp
